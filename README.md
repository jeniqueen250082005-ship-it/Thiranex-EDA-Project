Exploratory Data Analysis (EDA) Project

Project Overview

This project performs Exploratory Data Analysis on a Student Performance dataset to identify patterns, trends, and relationships between different factors affecting student performance.

Tools and Technologies

- Python
- Pandas
- Matplotlib
- Seaborn

Dataset

Student Performance Dataset ("student_data.csv")

Analysis Performed

- Dataset Preview
- Statistical Summary
- Attendance Analysis
- Study Hours Analysis
- Previous Score Analysis
- Final Score Analysis
- Correlation Analysis
- Performance Count Analysis

Project Outputs

- Assignment Score Histogram
- Attendance Histogram
- Correlation Heatmap
- Final Score Histogram
- Performance Count Chart
- Previous Score Histogram
- Sleep Hours Histogram
- Study Hours Histogram

Conclusion

The analysis helps identify patterns and relationships among student performance factors through statistical summaries and visualizations.
